# Mohammed Numaan - Portfolio Website

A minimalistic portfolio website showcasing projects, skills, and professional information with a clean black and white theme.

## Features

- **Responsive Design**: Works seamlessly on desktop, tablet, and mobile devices
- **Multiple Pages**: Home, About, Projects, Contact, and Bio Data sections
- **Clean Aesthetic**: Minimalistic black background with white text
- **Professional Layout**: Well-organized content with intuitive navigation

## Pages

- **Home**: Hero section with quick info cards
- **About**: Technical skills, career objective, achievements, and education
- **Projects**: Detailed project descriptions with tech stacks
- **Contact**: Contact information and social media links
- **Bio Data**: Personal information and educational background

## Technologies Used

- HTML5
- CSS3
- JavaScript (Vanilla)

## Getting Started

1. Clone the repository
2. Open `index.html` in your web browser
3. Add your profile photo as `photo.jpg` in the root directory

## File Structure

